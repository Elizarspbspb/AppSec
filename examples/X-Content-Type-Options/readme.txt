X-Content-Type-Options: nosniff

Потому что отсутствие nosniff — гораздо более контекстная проблема.

Нужно создать ситуацию, где сервер говорит браузеру что-то одно, а фактическое содержимое является другим.

Например, сервер может вернуть - Content-Type: text/plain
при этом тело ответа содержит HTML/JavaScript.

Поведение зависит от типа ресурса, контекста загрузки и браузера. Поэтому просто отсутствие X-Content-Type-Options ещё ничего страшного не доказывает.

nosniff говорит: "Не пытайся самостоятельно решить, что это за файл, если сервер уже указал тип."
Без nosniff браузеры могут пытаться определить настоящий тип содержимого самостоятельно — это называется MIME sniffing. 
С nosniff браузер должен гораздо строже придерживаться заявленного Content-Type.

Рекомендуется явно указать nosniff, когда работаем с разными типами данных, чтобы браузер корректно отображал страницу.
