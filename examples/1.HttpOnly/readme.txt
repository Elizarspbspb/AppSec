HttpOnly - атрибут cookie.

Например сервер отправляет: Set-Cookie: session=abc123; HttpOnly

HttpOnly говорит браузеру: Не разрешай JavaScript читать эту cookie.

Главным образом чтобы затруднить кражу сессионных cookies через XSS. 
Но XSS всё ещё может быть опасным: JavaScript может выполнять действия от лица пользователя в пределах доступных ему возможностей.
