Напишите код на python, который:

1. создаёт базу данных и таблицу. (Название колонок придумайте сами. Их должно быть 12)

2. в таблицу помещает следующие данные:

security_vulnerabilities = /*прилагаемый файл*/

При помощи SQL-запросов выполнить:

a. Найти уязвимости в компонентах Admin Panel и Reports — удалить эти записи.

b. Найти уязвимости с типом SQL Injection, у которых **дата_обнаружения > '2023-12-30 14:00:00'— изменить область на db (последний параметр записи).

c. Найти уязвимости, если у них область обнаружения = 'frontend', — заменить область обнаружения на full.

 

В качестве решения предоставить три числа:

сколько записей удалено по п. (a),

сколько записей обновлено по п. (b),

сколько записей обновлено по п. (c).
