Запуск Web + DB в Docker Compose



Вам выдан небольшой учебный проект:





папка web/ содержит веб-сервис на Flask;



этот сервис при каждом запросе обращается к базе данных PostgreSQL и показывает список заметок.

АРХИВ

Ваша задача — написать файл docker-compose.yml, который запускает:





контейнер с веб-сервисом;



контейнер с PostgreSQL.

И добиться, чтобы приложение корректно работало через один общий docker compose up.

 

Что известно о веб-сервисе

Веб-сервис уже готов и упакован в Docker-образ через web/Dockerfile.

Он ожидает подключение к базе PostgreSQL со следующими параметрами по умолчанию:





DB_HOST — db



DB_PORT — 5432



DB_NAME — labdb



DB_USER — labuser



DB_PASSWORD — labpass

Эти значения можно переопределять через переменные окружения для контейнера web, но можно оставить такими же и настроить под них сервис базы данных.

Сервис предполагается слушающим на порту 5000 внутри контейнера.

 

Что нужно сделать





Создать файл docker-compose.yml в корне каталога с проектом (там, где находится папка web/).



Описать в нём как минимум два сервиса:





web — ваш веб-сервис:





должен собираться из Dockerfile, находящегося в папке web/;



должен публиковать порт наружу (например, на localhost:8080, либо другой по вашему выбору);



должен иметь возможность достучаться до PostgreSQL по имени сервиса (например, db).



db — СУБД PostgreSQL:





использовать официальный образ PostgreSQL;



сконфигурировать базу, пользователя и пароль так, чтобы они совпадали с тем, что ожидает приложение
(по умолчанию labdb / labuser / labpass либо ваши собственные значения, но тогда их нужно передать веб-сервису через переменные окружения);



не обязательно публиковать порт БД наружу, достаточно, чтобы к ней мог обращаться контейнер web.



Настроить сеть между сервисами так, чтобы веб-сервис мог подключаться к базе по имени сервиса (например, db).



Запустить проект с помощью docker compose up и убедиться, что:





контейнеры web и db поднялись;



при открытии страницы веб-сервиса в браузере:





не показывается ошибка соединения с базой;



отображается хотя бы одна дефолтная заметка и можно добавить новые.

 

Что нужно сдать

Один файл (PDF или DOCX), в котором есть:





Текст вашего docker-compose.yml





Полностью, от начала до конца.

Требования к зачёту





Файл docker-compose.yml описывает как минимум два сервиса: веб и базу данных.



Веб-сервис успешно строится из Dockerfile и запускается через Docker Compose.



Веб-приложение реально работает: открывается в браузере и может взаимодействовать с базой (видно заметки, можно добавить новые).



В отчёте есть:





текст docker-compose.yml,



скриншот docker compose ps,



скриншот работающего приложения.

 





Подсказки







Для сервиса базы данных можно использовать официальный образ PostgreSQL и настроить его через переменные окружения (см. документацию к образу).



Имя сервиса базы данных в docker-compose.yml становится DNS-именем, по которому к нему может подключаться веб-сервис (host=db и т.п.).



Для веб-сервиса:





в docker-compose.yml используйте build с путём к каталогу web/;



не забудьте сделать проброс порта, чтобы открыть его из браузера.
