В этом задании:

1. Создайте верисию данного кода, где допущена сохранённая или отражённая XSS уязвимость 

2. Создайте верисию данного кода, где отсутствует сохранённая или отражённая XSS уязвимость

3. Уязвимый код должен запускать командой python vul.py runserver. В коде напишите полезуню нагрузку для выполнения уязвимости

4. Безопансый код должен запускать командой python safe.py runserver. В коде напишите полезуню нагрузку из предыдущего пункта (она уже не должна приводить к XSS)

 

Рекомендация: использует шаблонизатор. Для генерации уязвимого кода {{  <переменная>|safe }}

 

Для успешной сдачи задания:

1. оба кода должны работать

2. в качестве ответа прикрепите скриншоты выполнения XSS узявимости в уязвимой и в безопасных версиях (достаточно alert)
