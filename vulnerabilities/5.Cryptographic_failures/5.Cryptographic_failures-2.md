# Cryptographic Failures: Краткое руководство для AppSec специалиста

## Что такое криптографические уязвимости
**Криптографические сбои** — уязвимости из-за неправильного применения криптографии, ведущие к компрометации защищенных данных.

## Основные типы уязвимостей и способы поиска
1. **Слабые алгоритмы**
* Поиск в коде:
```bash
grep -R "MD5\|SHA1\|DES" .
```
* Примеры атак: коллизии, brute-force
* **Защита**: использование Argon2, bcrypt, scrypt
```python
from argon2 import PasswordHasher
ph = PasswordHasher()
hash = ph.hash("MyPassword123")
```

2. **Небезопасное управление ключами**
* Поиск секретов:
```bash
grep -R "password\|secret\|apikey" .
```
* Инструменты: GitLeaks, TruffleHog
* **Защита**: использование Vault, Key Vault, Secrets Manager

3. **Отсутствие шифрования**
* Проверка: SSL Labs, testssl.sh
* Атака: MITM
* **Защита**: TLS 1.2+, HSTS
```http
Strict-Transport-Security: max-age=31536000
```

4. **Ошибки реализации**
* Неправильный AES режим (ECB → GCM/CBC+HMAC)
* Слабые генераторы:
```python
# Плохо: import random
# Правильно: import secrets
token = secrets.token_hex(32)
```

## Последствия
* Утечка паролей и персональных данных
* Финансовые потери
* Нарушение комплаенса (GDPR, PCI-DSS)
* Репутационный ущерб

## Защита
1. Использовать современные алгоритмы:
* AES-256 для шифрования
* SHA-256 для хеширования
* TLS 1.2+ для передачи

2. Следить за:
* Безопасным хранением ключей
* Регулярной ротацией
* Криптостойкими генераторами

3. Проверять:
* Настройку протоколов
* Конфигурацию шифрования
* Управление сертификатами

4. Избегать:
* Жесткого кодирования секретов
* Использования устаревших алгоритмов
* Отключения проверки сертификатов
