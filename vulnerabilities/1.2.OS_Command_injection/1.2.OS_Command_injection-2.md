## 1. Что такое OS command injection
**OS Command Injection** — уязвимость, позволяющая выполнять произвольные команды ОС через веб-приложение. Злоумышленник может получить полный контроль над сервером и инфраструктурой.

## 2. Полезные команды для тестирования
| Цель | Linux | Windows |
|------|-------|---------|
| Текущий пользователь | `whoami` | `whoami` |
| Версия ОС | `uname -a` | `ver` |
| Сеть | `ifconfig` | `ipconfig /all` |
| Процессы | `ps -ef` | `tasklist` |

## 3. Слепые инъекции (Blind OS Command Injection)
**Слепые инъекции** — уязвимости без прямого вывода результата. Эксплуатация возможна через:
* Временные задержки
* Перенаправление вывода в файлы
* Внешние DNS-запросы

## 4. Методы обнаружения и эксплуатации
**Основные техники**:
* Временные задержки: `ping -c 10 127.0.0.1`
* Запись в файлы: `whoami > /path/file.txt`
* DNS-эксплойт: `nslookup evil.domain.com`

## 5. Способы внедрения команд
**Метасимволы для инъекций**:
* `&` — последовательное выполнение
* `||` — выполнение при ошибке
* `&&` — выполнение при успехе
* `|` — передача вывода
* `;` — разделитель команд (Unix)

## 6. Предотвращение атак
**Ключевые меры защиты**:
* Избегать прямых вызовов ОС-команд:
* Использовать встроенные API вместо shell-команд:
```py
# Плохо
os.system(f"ls {user_input}")
# Хорошо: использование безопасных API
import shutil
shutil.rmtree('/tmp/old_files')
```
* Применять безопасные библиотеки для работы с файлами:
```py
# Безопасный вызов с передачей аргументов
import subprocess
subprocess.run(["ls", user_input], shell=False)
```
* Минимизировать привилегии приложения
    * Запуск приложения от непривилегированного пользователя
    * Разделение критических операций на отдельные процессы

## 7. Методы валидации
**Эффективные подходы**:
* Белый список разрешённых значений
```py
allowed_values = ['option1', 'option2', 'option3']
if user_input not in allowed_values:
    raise ValueError("Неверное значение")
```
* Проверка числового формата
```py
if not user_input.isdigit():
    raise ValueError("Ожидалось число")
```
* Ограничение допустимых символов
```py
import re
if not re.match(r'^[a-zA-Z0-9_]+$', user_input):
    raise ValueError("Запрещенные символы")
```
* Контроль длины ввода
* Запрет спецсимволов через regex
* Запрет на экранирование:
```python
# НЕ ДЕЛАЙТЕ ТАК:
# user_input = user_input.replace(';', '').replace('&', '')
```

## 8. Дополнительные меры
**Усиление защиты**:
* Запуск приложения с минимальными правами
* Разделение привилегий между компонентами
* Использование `subprocess.run()` вместо `os.system()
```py
import subprocess
result = subprocess.run(
    ["command", "arg1", "arg2"],
    capture_output=True,
    text=True,
    check=True
)
```
* Внедрение WAF
    * Блокировка запросов с метасимволами: &, |, ;, `
    * Ограничение длины команд
    * Запрет опасных команд
* Регулярный аудит безопасности
    * Проверка прав доступа
    * Анализ логов на подозрительные команды
    * Тестирование на проникновение
* Мониторинг подозрительных команд
