# 1. Security misconfiguration
security misconfiguration — это общий тип уязвимости, который возникает из-за некорректной настройки компонентов системы: серверов, фреймворков, приложений, баз данных, сетевых сервисов и других элементов. Такая уязвимость может привести к несанкционированному доступу, утечке данных или другим проблемам безопасности. portswigger.net +3

На сайте PortSwigger есть информация о тестировании на наличие уязвимостей, связанных с неправильной конфигурацией безопасности. Например, в разделе поддержки есть статья «Using Burp to Test for Security Misconfiguration Issues», где рассказывается, как с помощью инструментов Burp Suite выявлять проблемы конфигурации. В ней упоминаются такие аспекты, как проверка списков директорий, настройка прав доступа к файлам и обнаружение небезопасных функций по умолчанию. 
Что относится к security misconfiguration

К этому типу уязвимостей можно отнести, например:

    Использование стандартных учётных записей и паролей. Многие устройства и программы поставляются с предустановленными учётными данными для первоначального доступа. Если их не изменить, злоумышленники могут использовать списки распространённых паролей для взлома системы. 
    Неудалённые тестовые аккаунты или функции. После развёртывания приложения часто остаются активные тестовые учётные записи, отладочные функции или примеры кода, которые могут быть использованы для атак. 
    Открытые порты и службы. Работа ненужные порты или службы повышают риск атаки. Например, если не закрыть порты, которые используются только в разработке, они могут стать точкой входа для злоумышленников. 
    Ошибки в настройках доступа к файлам. Некорректные права доступа к файлам, доступным через веб-сервер, могут позволить злоумышленнику читать или изменять данные. 
    Отсутствие шифрования или использование слабых алгоритмов. Незащищённые файлы или передача данных без шифрования облегчают несанкционированный доступ. 
    Проблемы с CORS (Cross-Origin Resource Sharing). Неправильная настройка заголовков CORS (например, Access-Control-Allow-Origin: *) может привести к утечке данных или выполнению кода на стороне клиента. learnhacking.io +2
    Детализированные сообщения об ошибках. По умолчанию серверы могут выдавать подробные сообщения об ошибках, включающие трассировки стека, версии компонентов и другую информацию, которую злоумышленники могут использовать для поиска уязвимостей. 
    Необновлённое ПО. Использование устаревших версий программного обеспечения с известными уязвимостями.
