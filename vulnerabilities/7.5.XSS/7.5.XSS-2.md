### Краткое руководство по XSS для AppSec специалиста

### Определение и суть XSS
**XSS (Cross-Site Scripting)** — уязвимость, позволяющая внедрить и выполнить вредоносный JavaScript-код в браузере жертвы через веб-приложение.

### Типы XSS-атак
* **Отражённая XSS** — код внедряется через HTTP-запрос и сразу возвращается в ответе
* **Хранимая XSS** — код сохраняется на сервере и показывается другим пользователям
* **DOM-based XSS** — уязвимость в клиентском JavaScript-коде

### Методы поиска XSS
**Этапы тестирования:**
* Идентификация точек ввода данных (параметры URL, формы, заголовки)
* Проверка отражения пользовательского ввода в ответе
* Определение контекста вывода (HTML, JavaScript, атрибуты)
* Тестирование базовых payload

**Базовые payload для проверки:**
* `<script>alert(1)</script>`
* `<img src=x onerror=alert(1)>`
* `javascript:alert(1)`
* `print()` (для обхода ограничений Chrome)

### Примеры уязвимостей
**Отражённая XSS:**
```html
https://site.com/search?q=<script>alert(1)</script>
```

**Хранимая XSS:**
```html
<p>Комментарий: <script>document.cookie=...;</script>
```

**DOM-based XSS:**
```javascript
var input = document.getElementById('userInput').value;
document.body.innerHTML = input;
```

### Методы защиты
**Основные меры защиты:**
* **Экранирование данных** в зависимости от контекста вывода:
  * HTML-кодирование для HTML-контекста
  * JavaScript-кодирование для JS-строк
  * URL-кодирование для URL
* **CSP (Content Security Policy)** настройка:
  * `script-src 'self'`
  * Использование nonce или хэшей для скриптов
* **Валидация ввода** по белому списку
* **HTTP-заголовки безопасности:**
  * `X-Content-Type-Options: nosniff`
  * `X-XSS-Protection: 1; mode=block`
  * `Content-Security-Policy`

### Последствия атак
* Кража сессий и учётных данных
* Выполнение произвольных действий от имени пользователя
* Распространение вредоносного кода
* Компрометация административных учётных записей

### Практические рекомендации
* Регулярно обновлять все компоненты приложения
* Использовать специализированные библиотеки для санитизации ввода
* Проводить аудит безопасности кода
* Тестировать на проникновение
* Следить за обновлениями CVE и патчами безопасности
