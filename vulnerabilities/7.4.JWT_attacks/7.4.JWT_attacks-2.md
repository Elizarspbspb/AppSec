# Краткое руководство по уязвимостям JWT

## Что такое JWT и основные компоненты
**JWT** (JSON Web Token) — формат передачи подписанных JSON-данных между системами. Состоит из трёх частей:
* Заголовок (header)
* Полезная нагрузка (payload)
* Подпись (signature)

## Основные уязвимости JWT
1. **Неправильная проверка подписи**
* Использование decode() вместо verify()
* Приём токенов с алгоритмом `"none"`
* Отсутствие проверки целостности подписи

2. **Слабые секретные ключи**
* Использование стандартных ключей из примеров
* Короткие или предсказуемые ключи
* Отсутствие ротации ключей

3. **Инъекции в заголовки**
* Манипуляции с параметрами jwk, jku, kid
* Подмена алгоритмов подписи
* Внедрение собственных ключей

## Способы обнаружения уязвимостей
**Анализ кода:**
* Проверка методов верификации токенов
* Анализ обработки заголовков JWT
* Поиск жёстко закодированных ключей

**Тестирование:**
* Изменение алгоритма подписи в заголовке
* Попытка отправки токена без подписи
* Модификация параметров jwk/jku/kid
* Использование Burp Suite JWT Editor для тестирования

## Примеры атак
* **Подмена алгоритма:**
```json
{
    "alg": "none",
    "typ": "JWT"
}
```

* **Внедрение собственного ключа:**
```json
{
    "jwk": {
        "kty": "RSA",
        "e": "AQAB",
        "n": "..."
    }
}
```

## Способы защиты
1. **Правильная настройка верификации:**
* Использовать только verify() для проверки токенов
* Явно указать разрешённые алгоритмы подписи
* Проверять все параметры заголовков

2. **Управление ключами:**
* Использовать длинные случайные ключи
* Регулярно менять секретные ключи
* Хранить ключи в безопасном хранилище

3. **Дополнительные меры:**
* Устанавливать срок жизни токенов (exp)
* Использовать параметр audience (aud)
* Реализовать механизм отзыва токенов
* Передавать JWT только через HTTP Headers

**Пример безопасной конфигурации (Node.js):**
```javascript
const jwt = require('jsonwebtoken');

// Проверка токена
jwt.verify(token, process.env.JWT_SECRET, {
    algorithms: ['HS256'],
    audience: 'your-app',
    complete: true
});
```

**Важные рекомендации:**
* Никогда не хранить чувствительную информацию в payload
* Использовать HTTPS для передачи токенов
* Регулярно обновлять JWT-библиотеки
* Валидировать все входящие токены перед использованием
