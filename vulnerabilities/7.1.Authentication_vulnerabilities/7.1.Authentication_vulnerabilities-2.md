# Краткое руководство по уязвимостям аутентификации
## Что такое уязвимости аутентификации
`Уязвимости аутентификации` — это слабые места в механизмах проверки подлинности пользователей, позволяющие злоумышленникам получить несанкционированный доступ к системе. Они возникают из-за:
* Слабой защиты от атак перебора
* Ошибок в логике реализации
* Недостаточной защиты данных пользователей

## Основные типы уязвимостей
* **Слабая защита от brute force** — отсутствие ограничений на количество попыток входа
* **Ошибки логики** — возможность обхода проверки подлинности
* **Утечка информации** — раскрытие данных о пользователях
* **Ненадежная MFA** — возможность обхода двухфакторной аутентификации

## Основные уязвимости и способы поиска
1. **Перечисление пользователей**
* Разные сообщения об ошибках
* Различия в HTTP-кодах
* Временные задержки при обработке
* Пример атаки:
```
POST /login HTTP/1.1
username=admin&password=wrong
```

2. **Brute force атаки**
* Автоматизированный перебор паролей
* Использование словарей
* Атака credential stuffing
* Инструменты: Burp Intruder, Hydra

3. **Обход MFA**
* Пропуск второго фактора
* Подмена токенов
* Перебор 2FA-кодов
* Пример уязвимого кода:
```python
if check_password(user, pass):
    create_session()  # Ошибка — сессия создается до проверки 2FA
```

## Способы защиты
1. **Базовая защита**
* Единое сообщение об ошибке
* Ограничение попыток входа (rate limiting)
* Временная блокировка при множественных ошибках
* CAPTCHA для подозрительной активности

2. **Защита MFA**
* Использование аппаратных токенов
* Приложения-аутентификаторы вместо SMS
* Привязка 2FA-кода к сессии
* Защита от перебора кодов

3. **Правильная реализация**
* Проверка всех факторов аутентификации
* Случайные токены для восстановления
* HTTPS для всех запросов
* Защита от перечисления пользователей

Пример защищенного кода:
```python
def login(username, password):
    if not check_password(username, password):
        return "Неверный логин или пароль"
    if not check_2fa(token):
        return "Неверный код 2FA"
    create_secure_session()
```

## Ключевые моменты для проверки
* **Логика аутентификации** — проверка всех этапов
* **Сообщения об ошибках** — отсутствие утечек информации
* **Временные задержки** — одинаковые тайминги для всех ответов
* **HTTP-ответы** — одинаковые коды для всех ошибок
* **Защита токенов** — случайность и уникальность

При обнаружении любой уязвимости в механизме аутентификации необходимо немедленно принять меры по её устранению, так как она может привести к компрометации всей системы.
